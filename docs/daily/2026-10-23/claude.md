# 2026-10-23 작업 기록

## 도입 상담 폼(/inquiry) 상품 구성 개편

### 요청
- 웹 리포트(campaign.clinicbridge.co.kr)의 무료 진단 버튼이 /inquiry로 연결됨. 상품 구성을 실제 판매 구성으로 정리 (Slack 스레드 10-23, 심영훈 안 기반, Koo 결정).

### 변경 (브랜치 `feat/inquiry-form-products`)
- `src/data/inquiryOptions.ts` 신규: 국가·서비스·목표 매출 선택지를 한곳에서 관리 (폼과 검증이 같은 목록 사용).
  - 국가: 일본 / 영미·영어권 / 대만 / 동남아 / 기타
  - 서비스: 국가별 전담 에이전시(월 500만 원 + 해외 환자 매출의 15% 또는 매출의 20~30%) / 바이럴 확산 마케팅 패키지(350만~500만 원) / Worldwide GTM 파트너십(별도 협의) / 아직 정하지 못했어요. 가격은 부가세 별도.
  - 목표 해외 환자 월 매출: 월 3천만~5천만 원 / 5천만~1억 원 / 1억 원 이상 (자유 입력 → 단일 선택)
- `InquiryForm.tsx`: 서비스 선택을 설명·가격이 보이는 카드형 복수 선택으로, 목표 매출을 단일 선택으로 변경. 월 예산은 자유 입력 유지(예시 '월 500~1,000만원'). 주소의 utm 값을 숨김 칸 `inflow`로 저장.
- `validators.ts`: `inflow`(선택) 추가, 목표 매출 안내 문구 변경.
- `api/inquiry/route.ts`: 유입 경로를 Slack·Trello·메일·시트에 추가(없으면 '직접 방문'). 알림 문구 '기대' → '목표 해외 환자 월 매출'.
  - **시트 열 이름은 '기대 해외 환자 월 매출' 유지** — 열 이름으로 매핑되므로 바꾸면 새 열이 생겨 기존 데이터와 나뉜다. 시트 '유입 경로' 열은 Apps Script가 자동 추가.

### 영향분석
- 응답 계약(`ok`, `inquiryId`)과 전환 집계(OpenAI lead_created, gtag) 변경 없음.
- 저장 형식: `interests`·`targetCountries`는 여전히 문자열 배열, `expectedRevenue`·`budget`은 문자열 → Slack/시트/Trello/메일 처리 그대로.
- 삭제된 서비스명(LINE 계정 세팅, 월 정기 운영 플랜, 애드온 서비스)은 과거 시트 행에만 남는다.
- `/pricing` 페이지는 아직 예전 상품 구성 → 가격 표기가 서로 다르므로 후속 정리 필요. 약관의 상품명도 후속 수정(이은석 대표 의견).
- 다른 폼(`/api/contact`, `/api/diagnosis`) 영향 없음.

### 디자인 개선 (같은 브랜치)
- 서비스 카드: 체크박스에 체크 표시(lucide `Check`), 선택 시 테두리·링 강조, 가격을 브랜드 컬러 굵은 글씨로(PC는 제목 오른쪽, 모바일은 제목 아래). 가격 없는 '아직 정하지 못했어요'는 점선 테두리로 상품과 구분.
- 라벨: '복수 선택 가능', '가격은 부가세 별도'를 제목 옆 옅은 안내(`hint`)로 분리.
- 브랜드 컬러는 `primary` 토큰만 사용 (docs/design 규칙).
- 확인: tsc·eslint 통과, 1280px·390px 캡처.

### 3단계 폼으로 재구성 (같은 브랜치)
- 근거(간단 조사): 항목이 많은 리드 폼은 단계를 나누고 부담 적은 질문부터, 민감한 질문(매출·예산·연락처)은 뒤로 / 진행 표시와 대화체 단계 제목 / 2~4개 선택지는 숨기지 않고 큰 카드·버튼으로 (orbitforms, involve.me 등 업계 가이드).
- 1단계 "어떤 도움이 필요하신가요?": 관심 서비스(카드) → 희망 국가. 2단계 "병원 상황을 알려주세요": 목표 매출·월 예산·소개·어려움·도입 시기. 3단계 "연락받으실 정보": 연락처·동의.
- '다음'은 해당 단계 항목만 검증(react-hook-form `trigger`). 진행 막대(3칸)와 '약 2분' 표시, 단계 전환 시 폼 상단으로 스크롤.
- 국가별 전담 에이전시 가격을 요금 방식별 두 칸(기본료 + 성과 / 성과 연동)으로 분리 (`inquiryOptions.ts`의 `prices` 배열).
- 국가·목표 매출 선택지에도 체크 표시, 터치 영역 44px 이상. 입력 칸 높이·글자 키움, 전화·이메일 `inputMode`.
- 응답 계약·전환 추적·API 변경 없음 (제출은 마지막 단계에서 한 번).
- 확인: tsc·eslint 통과, CDP로 1단계 선택 → 2단계 이동 → 빈 칸 오류 표시를 390px·1280px에서 캡처.

### 관심 서비스 단일 선택 + 전담 에이전시 2개 상품 분리 (같은 브랜치)
- 국가별 전담 에이전시를 요금 방식이 다른 두 상품으로 분리: '국가별 전담 에이전시 (기본료 + 성과)' 월 500만 원 + 해외 환자 매출의 15% / '국가별 전담 에이전시 (성과 연동)' 해외 환자 매출의 20~30%.
- 관심 서비스는 하나만 선택(라디오 카드, 동그라미 표시). 저장 형식은 문자열 배열을 유지하고 한 개만 담는다 → API·Slack·시트 변경 없음.
- 목표 매출도 단일 선택 표시(동그라미)로 통일. 희망 국가는 복수 선택 유지(네모 체크).
- 확인: tsc·eslint 통과. CDP로 '기본료 + 성과' → '성과 연동' 순서로 눌러 하나만 선택되는 것 확인(390px·1280px).

### 팀 검토용: 한 페이지 버전 추가 (같은 브랜치)
- `/inquiry?layout=single` → 같은 항목을 한 페이지에 번호 섹션(1 무엇이 필요한지 · 2 병원 상황 · 3 연락처)으로 보여준다. 기본 `/inquiry`는 3단계 폼.
- 단계별 입력 항목을 `stepBodies` 배열로 묶어 두 버전이 같은 항목·검증·제출 로직을 쓴다.
- **두 버전 중 하나로 정해지면 `singlePage` 분기를 지운다** (임시 비교용).
- 확인: tsc·eslint 통과, 390px·1280px 전체 캡처, 빈 칸 제출 시 오류 표시.
