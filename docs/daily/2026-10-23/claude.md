# 2026-10-23 작업 기록

## 도입 상담 폼(/inquiry) 상품 구성 개편

### 요청
- 웹 리포트(campaign.clinicbridge.co.kr)의 무료 진단 버튼이 /inquiry로 연결됨. 상품 구성을 실제 판매 구성으로 정리 (Slack 스레드 10-23, 심영훈 안 기반, Koo 결정).

### 변경 (브랜치 `feat/inquiry-form-products`)
- `src/data/inquiryOptions.ts` 신규: 국가·서비스·목표 매출 선택지를 한곳에서 관리 (폼과 검증이 같은 목록 사용).
  - 국가: 일본 / 영미·영어권 / 대만 / 동남아 / 기타
  - 서비스: 국가별 전담 에이전시(월 500만 원 + 해외 환자 매출의 15% 또는 매출의 20~30%) / 바이럴 확산 마케팅 패키지(350만~500만 원) / Worldwide GTM 파트너십(별도 협의) / 아직 정하지 못했어요. 가격은 부가세 별도.
  - 목표 해외 환자 월 매출: 월 3천만~5천만 원 / 5천만~1억 원 / 1억 원 이상 (자유 입력 → 단일 선택)
- `InquiryForm.tsx`: 서비스 선택을 설명·가격이 보이는 카드형 복수 선택으로, 목표 매출을 단일 선택으로 변경. 월 예산은 자유 입력 유지(예시 '월 500~1,000만원'). 주소의 utm 값을 숨김 칸 `inflow`로 저장.
- `validators.ts`: `inflow`(선택) 추가, 목표 매출 안내 문구 변경.
- `api/inquiry/route.ts`: 유입 경로를 Slack·Trello·메일·시트에 추가(없으면 '직접 방문'). 알림 문구 '기대' → '목표 해외 환자 월 매출'.
  - **시트 열 이름은 '기대 해외 환자 월 매출' 유지** — 열 이름으로 매핑되므로 바꾸면 새 열이 생겨 기존 데이터와 나뉜다. 시트 '유입 경로' 열은 Apps Script가 자동 추가.

### 영향분석
- 응답 계약(`ok`, `inquiryId`)과 전환 집계(OpenAI lead_created, gtag) 변경 없음.
- 저장 형식: `interests`·`targetCountries`는 여전히 문자열 배열, `expectedRevenue`·`budget`은 문자열 → Slack/시트/Trello/메일 처리 그대로.
- 삭제된 서비스명(LINE 계정 세팅, 월 정기 운영 플랜, 애드온 서비스)은 과거 시트 행에만 남는다.
- `/pricing` 페이지는 아직 예전 상품 구성 → 가격 표기가 서로 다르므로 후속 정리 필요. 약관의 상품명도 후속 수정(이은석 대표 의견).
- 다른 폼(`/api/contact`, `/api/diagnosis`) 영향 없음.
